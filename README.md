# Amazon Product Analysis

## Overview
This project analyzes Amazon product data using Python and Excel.

## Tools Used
- Python (pandas)
- Microsoft Excel
- Pivot Tables
- Data Visualization

## Process
1. Cleaned and transformed raw product data using Python.
2. Created additional metrics such as discount amount.
3. Built pivot tables to analyze category-level trends.
4. Created a dashboard with pivot charts to visualize ratings, discounts, and customer engagement.

## Files
- script.py
- amazon.csv
- cleaned_data.csv
- analysis.xlsx

Amazon Product Dataset from Kaggle.
